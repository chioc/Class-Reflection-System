# Re:Point 振り返りシステム

Googleフォーム＋スプレッドシート＋Google Apps Script（GAS）で運用する授業振り返りシステムです。

## セキュリティ上の必須設定

| 対象 | 設定 |
|---|---|
| Webアプリのデプロイ | 「次のユーザーとして実行：**自分**」「アクセスできるユーザー：**（組織名）内の全員**」 |
| Googleフォーム | 「メールアドレスを収集：**確認済み**」「**（組織名）のユーザーに限定する**」をオン |
| スプレッドシート／GASプロジェクト | 共有は**先生のみ**。リンク共有は「制限付き」 |
| スクリプトプロパティ `TEACHER_EMAILS` | 先生のアドレスを「,」区切りで設定（**スクリプトの所有者も必ず含める**） |

### 点検方法
GASエディタで `checkSecuritySettings` を実行すると、上記の設定を点検して結果をログに出します。
フォームのメール収集が「確認済み」でない場合は `fixFormEmailCollection` で変更できます。

### 任意の設定（スクリプトプロパティ・シート）
| 項目 | 内容 |
|---|---|
| 「名簿」シート | A列：メールアドレス、B列：クラス。あると、広場のクラスは名簿で決まる（フォームで別クラスを選んでも他クラスの広場は見られない）。`setupRosterSheet` で下書きを作成できる |
| `AI_DAILY_LIMIT_PER_USER` | 1人1日あたりのAIコメント生成回数の上限（既定 5、0で無効） |
| OpenAI | このシステム専用のAPIキーを使い、プロジェクトに月の予算上限を設定する |

### コード側の安全装置
- 画面に表示する文字はすべてHTMLエスケープ（生徒の入力・AIの出力によるスクリプト実行を防止）
- デプロイが「アクセスしているユーザーとして実行」になっている場合、生徒の利用を止める
- フォームのメール収集が「確認済み」でない場合、生徒向けの記録表示を止める（なりすまし防止）
- 生徒の記述はAIへ「データ」として区切って渡し、記述内の命令には従わせない（プロンプトインジェクション対策）。推定テーマは整形してからユーザーメッセージ側で渡す
- シートへの書き込みは `= + - @` で始まる文字列を数式として扱わせない（数式インジェクション対策）。AI出力からHTMLタグを除去
- 管理用・定期実行の関数は、生徒がブラウザから呼んでも動かない
- エラーの詳細は生徒に見せず、R列（先生用）とログに記録
- 広場の匿名番号は毎回ランダムに付け直す。広場には先生コメントを出さず、赤線の位置だけを共有する
- CDNのBootstrapは SRI（integrity）付きで読み込む

※ 今回の更新で FormApp・DriveApp を使うため、初回実行時に権限の再承認が必要です。

## 赤ペン確認（教師専用）
Webアプリの「赤ペン確認」タブで、生徒の振り返りの大事な言葉に赤線を引き、確認スタンプ・先生コメントを保存できます。
- 下線・スタンプは「教師チェック」シートに保存します（回答本文は変更しません）。このシートは先生だけに共有してください
- 生徒の「個人の記録」には赤線・スタンプ・先生コメントが、「クラスの広場」には赤線だけが表示されます
- 回答本文が後から変わった提出では、古い赤線・スタンプは表示されません

## 表示の高速化
データが増えても表示が遅くならないよう、次の工夫をしています。
- 個人の記録・クラスの広場（日付×クラス）・提出日の一覧を、サーバー側のキャッシュ（CacheService）に置く。
  2回目以降はシートを読まずに表示する（クラス全員が同時に広場を開いても、シートは1回しか読まない）
- 日付で絞る処理（広場・分析・素案作成・再生成・赤ペン）は、A列だけを読んでその日の行だけを読み込む
- 1回の処理の中で、スプレッドシートを開く処理・設定の読み込みは1度だけ行う
- 最初の画面に個人の記録を埋め込み、サーバーとの往復を1回減らす。生徒の広場の日付一覧は手元の記録から作る

キャッシュは、フォーム送信・AIコメントの書き込み・赤ペンの保存・再生成のときに自動で消えるので、古い内容は表示されません。

### 初回の設定（推奨）
GASエディタで `setupFastLoading` を一度実行してください。先生がスプレッドシートを直接編集（先生コメントの入力、行の削除・並べ替えなど）したときにも、キャッシュが自動で消えるようになります。
- 実行前：先生がシートを直接編集した内容は、最大2分遅れて表示されます（キャッシュの有効時間を2分にしています）
- 実行後：キャッシュの有効時間が6時間になり、より速く表示されます
- 表示がおかしいときは `clearAllCaches` を実行すると、すべてのキャッシュを消せます
- 元に戻すときは `stopFastLoading` を実行します
