# Re:Point 振り返りシステム

Googleフォーム＋スプレッドシート＋Google Apps Script（GAS）で運用する授業振り返りシステムです。

## セキュリティ上の必須設定

| 対象 | 設定 |
|---|---|
| Webアプリのデプロイ | 「次のユーザーとして実行：**自分**」「アクセスできるユーザー：**（組織名）内の全員**」 |
| Googleフォーム | 「メールアドレスを収集：**確認済み**」「**（組織名）のユーザーに限定する**」をオン |
| スプレッドシート／GASプロジェクト | 共有は**先生のみ**。リンク共有は「制限付き」 |
| スクリプトプロパティ `TEACHER_EMAILS` | 先生のアドレスを「,」区切りで設定（**スクリプトの所有者も必ず含める**） |

### 点検方法
GASエディタで `checkSecuritySettings` を実行すると、上記の設定を点検して結果をログに出します。
フォームのメール収集が「確認済み」でない場合は `fixFormEmailCollection` で変更できます。

### コード側の安全装置
- 画面に表示する文字はすべてHTMLエスケープ（生徒の入力・AIの出力によるスクリプト実行を防止）
- デプロイが「アクセスしているユーザーとして実行」になっている場合、生徒の利用を止める
- フォームのメール収集が「確認済み」でない場合、生徒向けの記録表示を止める（なりすまし防止）

※ 今回の更新で FormApp・DriveApp を使うため、初回実行時に権限の再承認が必要です。
